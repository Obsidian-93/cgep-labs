This Terraform module provisions a primary S3 bucket, paired with a dedicated log-destination bucket, that together enforce five NIST 800-53 controls as code rather than as manual configuration or screenshots. SC-28 (Protection of Information at Rest) is satisfied through AES-256 server-side encryption applied by default to every object in both buckets. CM-6 (Configuration Settings) is enforced twice over: mandatory compliance tags (Project, Environment, ManagedBy, ComplianceScope) are applied automatically to every resource via the provider's default_tags, and object versioning on the primary bucket prevents silent, untracked overwrites. AC-3 (Access Enforcement) is guaranteed by a public access block on both buckets with all four blocking flags set to true, actively preventing public exposure rather than merely defaulting to it. AU-3 (Content of Audit Records) and AU-6 (Audit Record Review, Analysis, and Reporting) are satisfied together by wiring S3 access logging from the primary bucket to the log bucket, which is itself encrypted and access-blocked using ownership controls and an ACL scoped specifically to log delivery. Every control was verified independently of Terraform's own state, confirmed directly against the live AWS API, and captured as machine-readable JSON evidence.
